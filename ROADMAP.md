# Roadmap

Planned work on this project:

## Security
- [ ] Replace client-side "encryption" with proper server-side sessions (HttpOnly cookies)
- [ ] Add role-based access and audit logging for admin actions

## Code quality
- [ ] Migrate from the Pages Router to the App Router
- [ ] Add ESLint/Prettier rules and remove dead code
- [ ] Share typed API models with the backend

## Features
- [ ] Bulk moderation tools for user images
- [ ] Scheduling and preview for events and notifications
- [ ] Dashboard with contest and membership statistics

## Testing and DevOps
- [ ] Unit tests (Vitest) and Playwright end-to-end tests
- [ ] GitHub Actions workflow for lint, type-check and build
- [ ] Dockerfile
